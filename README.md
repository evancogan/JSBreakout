## _What is it?_
This is a work-in-progress implementation of breakout in JavaScript, for the purposes of teaching me physics through _matter.js_

## How to play
Download the code and host a live server with a live server extension, or run

```python
start "" python -m http.server 8000
timeout /t 2 >nul
start "" "http://localhost:8000"
```

but Python is required
